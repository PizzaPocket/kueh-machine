# Character sprite standard

Use five dialogue states for every production customer:

- `neutral`
- `worried`
- `thinking`
- `happy`
- `remembering`

All five states must use a square transparent PNG, consistent character scale and consistent padding.

Every `happy` sprite must include two or three small detached joy marks. Use warm golden shimmer stars, rounded exclamation rays, or a restrained combination of both. Keep these marks outside the character silhouette and do not add a halo or glowing outline around the character.

The current core happy sprites follow this rule:

- Ondeh-Ondeh uses rounded golden joy rays.
- Ang Ku Kueh uses golden shimmer stars and joy rays.
- Kueh Lapis uses golden shimmer stars.

Apply the same rule when producing the five separate dialogue sprites for later international customers, including the Luk Chup trio.

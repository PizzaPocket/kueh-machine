# Beary's Kueh Shop — Story Game V2

This folder is a non-destructive design and implementation handoff. The existing V1 files at the project root have not been changed.

## Start here

1. Read `docs/CLAUDE-HANDOFF.md`.
2. Use `data/chapter-schema.example.json` as the contract between story content and the game engine.
3. Treat the images in `assets/character-concepts/` as visual-direction sheets, not final transparent sprites.
4. Reuse the existing desktop tray at `../assets/tray.png`; use `assets/ui/tray-mobile-concept-v1.png` as the portrait/mobile frame concept.

## Current art status

- Desktop tray: existing production asset.
- Mobile tray: concept ready for responsive prototyping.
- Three starter customers: concept sheets ready for review.
- Individual transparent expressions, card art, minigame pieces, and memory fragments: create only after the character direction is approved.

## Important content rule

Historical, regional, ingredient, pronunciation, and tradition claims must be verified with reliable cultural or institutional sources before publication. Story dialogue may be fictional, but educational facts must not be invented.
